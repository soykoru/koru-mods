# koru-mods

Mods KORU Link que instala **KORU Live** (soykoru.stream). La app solo usa el índice `manifest.json` si su firma (`manifest.json.sig`) es del dueño.

## Dependencias
No se alojan aquí: la app las baja de la página oficial de cada proyecto, con la huella fijada en el índice.

- **BepInEx 5.4.23.5 (64 bits)** — LGPL-2.1 — https://github.com/BepInEx/BepInEx
- **BepInExPack Valheim 5.4.2351** — LGPL-2.1 (BepInEx); incluye DLL de Unity sin recortar del pack de Thunderstore — https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/
- **SMAPI 4.5.2** — LGPL-3.0 — https://smapi.io/
- **tModLoader (gratis en Steam)** — MIT — https://store.steampowered.com/app/1281930/tModLoader/
- **Fabric Loader 0.19.5 (Minecraft 26.3)** — Apache-2.0 — https://fabricmc.net/
- **Fabric API 0.161.0+26.3** — Apache-2.0 — https://modrinth.com/mod/fabric-api
